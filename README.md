# Alder for Mac

A press-Play-and-it-plays Stremio client for one 2014 MacBook Air on Big Sur: a thin native shell with a web interface and libmpv for playback.

**Test app, not yet usable.** This repository currently holds only the proof that the approach can work on that machine.

## Credit

Ported from [`esedmemmed/Alder-tizen`](https://github.com/esedmemmed/Alder-tizen), the Samsung TV port of [Alder](https://github.com/aradhyas8/Alder) by aradhyas8, the Android TV client.
