# Opening Alder on your Mac for the first time

1. Double-click the Alder file you downloaded (it ends in `.dmg`). A small window opens.
2. In that window, drag the Alder icon onto the Applications folder.
3. Eject it: in the Finder sidebar, click the eject arrow next to Alder (or drag it to the Trash).
4. Open the Applications folder. Hold Control and click Alder, choose Open, then click Open again.
   You only do this once.
5. If you only saw a warning and no Open button: open System Preferences > Security & Privacy >
   General, click Open Anyway next to Alder, then click Open.

After that, open Alder from Applications or the Dock like any other app.

Each new beta may ask this once again: repeat step 4 (or 5).

To see which version you have: open Alder, go to Settings; the version is shown there.

Your sign-in stays when you install a new beta; you do not need to sign in again.
